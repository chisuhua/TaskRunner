# src/umd/ - UMD Evolution (Experimental)

User-Mode Driver evolution scope. **PROPOSED/DRAFT** — code compiles only under `TASKRUNNER_BUILD_MODE=umd-evolution` (the default since 2026-07-09). Two sub-systems: (1) `CudaRuntimeApi` (Phase 1) and (2) `libcuda_shim/` (LD_PRELOAD driver shim).

## OVERVIEW

| File/Dir | LOC | Role |
|----------|-----|------|
| `cuda_runtime_api.cpp` | 210 | `CudaRuntimeApi` class — links into both CLI and shim (always built) |
| `libcuda_shim/` | ~2000 | 16-file CUDA driver shim (`cu_*.cpp`) + 1 auto-generated `cu_stub_table.inc` producing `libcuda_taskrunner.so` |

## WHERE TO LOOK

| Task | Start here |
|------|------------|
| Add CUDA runtime API method | `cuda_runtime_api.cpp` + `include/umd/cuda_runtime_api.hpp` |
| Add LD_PRELOAD shim symbol | `libcuda_shim/cu_*.cpp` (e.g., `cu_mem.cpp` for `cuMemAlloc`) |
| Shim init / runtime accessor | `libcuda_shim/cu_init.cpp` (`cuInit()` strong symbol + `runtime()`) |
| Shim stub table | `libcuda_shim/cu_stub_table.inc` (auto-generated, do not edit) |
| Understand shim patterns | `libcuda_shim/cu_init.cpp` (weak→strong override pattern) |

## CONVENTIONS

- `CudaRuntimeApi` compiles in BOTH `test-fixture` and `umd-evolution` modes (CLI depends on it)
- `libcuda_shim/` compiles ONLY in `umd-evolution` mode (TestFixture.cmake excludes it)
- Shim uses weak→strong override: shim provides strong symbol that overrides weak in static lib
- All `cu_*.cpp` files have `// SCOPE: UMD-EVOLUTION` first line (16 files; `cu_stub_table.inc` is auto-generated, no SCOPE line)
- `cuda.h` in `include/` (root, not `include/umd/`) is also UMD-EVOLUTION — see deviation note in root AGENTS.md

## ANTI-PATTERNS

- **NEVER** call shim symbols from `cuda_runtime_api.cpp` — shim is loaded via LD_PRELOAD, not linked
- **NEVER** edit `cu_stub_table.inc` — regenerated by `tools/generate_cu_stubs.py`
- **NEVER** add `// SCOPE: UMD-EVOLUTION` to files outside `src/umd/`, `include/umd/`, `include/cuda.h`
- **NEVER** mark a UMD file as ACCEPTED without promoting via TADR (`docs/umd-evolution/adr/`)

## BUILD MODE INTERACTION

```bash
# Default (umd-evolution): full UMD build
cmake -B build && cmake --build build
# Produces: libcuda_taskrunner.so + taskrunner + 14 test executables

# Opt-out (test-fixture): CLI + test_fixture tests only
cmake -B build -DTASKRUNNER_BUILD_MODE=test-fixture
# Still builds: src/umd/cuda_runtime_api.cpp (CLI needs it)
# Excludes: src/umd/libcuda_shim/* + tests/umd/*
```
